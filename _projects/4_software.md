<a href="https://github.com/Goyal-STIR-Group/splidar">GitHub repository</a>

A Python library for simulating Single-photon lidar (SPL) measurements, estimating scene parameters, and computing the Cramér-Rao bound (CRB) for various models of SPL, with a focus on dead times.

This code can be used to reproduce (single-pixel) simulation results in
- Kitichotkul et al., "The Role of Detection Times in Reflectivity Estimation With Single-Photon Lidar," JSTQE, 2024.
- Kitichotkul et al., "Free-running vs Synchronous: Single-Photon Lidar for High-flux 3D Imaging," ICCV 2025.
- Kitichotkul, "Single-Photon Lidar: Statistical Analysis, High-Flux Imaging, and Velocimetry," Boston University, 2026.
